# Hami_Mini_Market
Hami MiniMarket is a simple responsive website built with **HTML**, **CSS**, and **JavaScript**.  
It showcases a local organic food shop offering fresh fruits and vegetables.

## Features
- Responsive design for all devices  
- Hero section with tagline and “Shop Now” button  
- Product showcase grid  
- About Us section  
- Contact form with JavaScript validation  
- Live product search (filters products as you type)  
- Footer with contact info and social media links
## Technologies Used
- HTML5  
- CSS3 (Flexbox and Grid)  
- JavaScript (Vanilla)  
- Font Awesome Icons
